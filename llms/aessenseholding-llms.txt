# AEssenseGrows (AEssense Corporation)

> AEssenseGrows designs and manufactures fully automated, zero-soil aeroponic SmartFarms
> for commercial indoor growers, driven by its own Guardian Grow Manager control
> software. Founded in Silicon Valley in 2014, headquartered in San Jose, California,
> with a second facility in Shanghai, China. AEssenseGrows publishes NO public API, no
> developer portal, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any package registry
> and no GitHub organization. Guardian ships only as an operator web application bundled
> with the hardware it controls. This file was generated by API Evangelist from the
> company's public website; it is not published by AEssenseGrows.

## Products

- [Guardian Grow Manager automation software](https://www.aessensegrows.com/en/guardian-grow-manager-automation-software): Sensor-driven control software that automates nutrient dosing, irrigation, photoperiod, pH, CO2, humidity and temperature against customer-authored Grow Plan recipes, with data logging, alerting and analytics. Delivered with the hardware; no public API.
- [Guardian Grow Manager remote access](https://www.aessensegrows.com/en/guardian-system/aetrium-guardian-grow-manager-remote-access): Browser-based remote monitoring and control of active machines. Access is by demo request; there is no documented programmatic interface.
- [AEtrium System overview](https://www.aessensegrows.com/en/guardian-system): The integrated aeroponic hardware plus software platform.
- [AEtrium product catalog](https://www.aessensegrows.com/en/cultivation): AEtrium-2.1 cloning and vegging SmartFarm, AEtrium-4 and Double Deck AEtrium-4 bloom systems, Nursery-6, and the AEtrium Automated Dosing Unit.
- [Aerix LED lighting](https://www.aessensegrows.com/en/lighting/led/aerix): Horticultural LED fixtures; the AExcel, AEdge and Blaze lines are covered in the document library.
- [Design, build, test, train, transfer services](https://www.aessensegrows.com/en/cultivation/design-build-test-train-transfer-services): Consulting and facility transfer practice.
- [AEssenseFresh](https://www.aessensefresh.com/): The company's fresh-produce brand, running the same platform for leafy greens.

## For agents

- There is no API to call. No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL, MCP server or A2A agent card exists on any AEssenseGrows host; every named `/.well-known/` path returns 404.
- Guardian Grow Manager was licensed in 2018 to integrate California's Metrc seed-to-sale track-and-trace system, which makes it a CONSUMER of a third-party regulatory API, not a publisher of one.
- The only machine-readable index the company serves is [its sitemap](https://www.aessensegrows.com/sitemap.xml).
- The aessensefresh.com brand site blocks major AI crawlers (ClaudeBot, GPTBot, CCBot, Google-Extended and others) by Squarespace default; aessensegrows.com allows them.
